First public release.

### Major changes
- Terminals grouped by work folder; a folder is added automatically when an agent runs in it
- Agent status on each terminal, with a sound and a mark when an agent stops
- Multiple Claude and Codex accounts, with per-account usage in the status bar
- Switch accounts in an open Claude terminal and keep the same conversation
- Split panes with a saved layout per group; drag tabs between panes
- File list with Git change marks, image and PDF preview, and file paste or drop into terminals

### Minor changes
- WSL terminals get 24-bit color; the Git view opens repositories in WSL folders
- Korean input fixes; macOS Cmd shortcuts work during composition
- Terminal rendering fixes for emoji width and broken glyphs after returning to the window
- Light theme, app icons for macOS and Windows installers
