### Major changes
- Terminals keep running after the app closes; choose to keep or stop them on quit (`paddock.backend.onQuit`)
- Terminals whose process ended are restored in the same folder with the saved screen, and Claude or Codex conversations resume
- Account profiles share settings, commands, agents, hooks, rules and MCP servers with the default account
- WSL folders run Git inside WSL, fixing slow status and object errors on large repositories
- Search in files works without opening a workspace

### Minor changes
- Memory gauge shows WSL usage and the largest terminal, and warns before memory runs out
- Fewer false stop alerts: status reported by the agent takes priority
- Typing stays responsive while Claude is working; the backend no longer stalls on macOS process checks or conversation lookup
- Enter during Korean composition no longer leaks into the terminal when closing a dialog
- Extension error popups become notifications; extension READMEs load
- Move a tab back from a separate window; new windows no longer duplicate terminals
- Review notes paste into the agent terminal in one step
- Log size limits and event logging for crashes and unresponsive windows
